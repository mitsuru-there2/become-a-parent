# 子育てシミュレーター（仮称）

子育てのあるあると、ボードゲームのような偶然から生まれる予想外の人生を笑って楽しむゲーム。最期には家族と自分の幸せを振り返ります。ビジュアルはモノクロでシュールな方向です。

現在は計画段階で、SPEC 1.0の詳細仕様と机上確認をまとめ、一括レビューを待っています。ゲーム・CLIは未実装です。半年単位・全40ターンの育児から親の老後・最期までを5つの基本パターンで比較し、テキスト版PoC → ビジュアル化 → バリエーション追加の順に進めます。
