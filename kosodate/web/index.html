親伝説 — Become a Parent

半年ごとの、小さな選択。

  1. 家族の様子を読む

    子どもの言葉や行動、親の疲れを見て、今期の過ごし方を考えます。

  2. 今期の方針を決める

    4つの方針でまとめて変更するか、個別に編集できます。使える時間は親それぞれ12単位。世話は必要量ちょうどに配分します。活動は3歳からです。

  3. 出来事に答える

    選択肢をクリックすると回答が保存されます。費用と収支を見ながら、半年を確定するまでは選び直せます。

  4. 半年を進める

    回答と配分が揃うと確定できます。全40期のあと、親の老後と最期、家族の人生を振り返ります。

方針・回答・進行は操作ごとに保存されます。個別編集は「方針を保存」を押してください。同じ保存先で起動すると、続きから遊べます。

数値はこの作品のルールであり、現実の育児や人生を予測するものではありません。
