# SPEC

版：1.0。作成日：2026-09-12。更新日：2026-09-13。

状態：人生全体を通すテキスト版PoCの初版仕様を具体化済み。一括レビュー待ち。S-001〜S-012は**実装対象・未実装**。数式の机上確認を実施したが、CLIの実装、AIの通常プレイ、人の面白さ検証はまだ行っていない。

ユーザーがSP-01の推奨案を承認し、残る仕様を推奨案で決めて最後にまとめてレビューする進め方を指定した。今回の詳細はその委任に基づく採用設計で、個々の数値までユーザーが確認済みとは扱わない。数値は初版で使う具体的な調整仮値であり、実証的な育児・寿命・幸福のモデルではない。実装開始は今回の依頼範囲に含めない。

この文書と以下の分冊がゲーム規則の正本。企画は[ゲーム企画](game-concept.md)、策定進捗は[仕様策定計画](specification-plan.md)、採用理由は[意思決定記録](decisions.md)、残る仮説と将来範囲は[未決事項](open-questions.md)。同じ規則を各文書へ複製せず、分冊の該当Sを参照する。

## レビューの入口

まず[5本の机上結果](specs/desk-check.md)で体験の違いと偏りを確認し、次に[行動と更新](specs/core.md)、[イベント](specs/events.md)、[老後と評価](specs/ending.md)を読むことを推奨する。技術面は[CLI契約](specs/cli.md)、実装後の確認は[検証計画](specs/verification.md)。

主なレビュー事項は、時間配分の細かさ、出来事のコメディの調子、親ごとの最期、幸福の配点、支援的な方針が上限に達しやすいバランス。後者は既知の調整仮説としてQ-014に残した。入力・処理・終了の必須仕様に未定義のまま実装へ渡す箇所は残さない。

## 初期PoCの範囲と版

既定のコメディ、子ども1人、半年・40ターン、20歳後の自動進行、親子の評価を分ける方針を維持する。比較対象は合意した5本。親2人の同じ家庭を基本に、個人差比較では子どもの新しい場への慣れ方だけを変える。

ルール・データ・操作・保存の初版IDはCLI契約で定義する。バリエーション、ビジュアル、複数の子ども、詳細な深刻事件、製品向け互換性は後続範囲。人生の途中の年代、親の最期、最終評価は初期PoCに含まれる。

## 数値確認の根拠

[机上確認記録](specs/desk-check.md)に、5本の全期間の数値付き抜粋と50計算の比較を記録した。[全入力・状態・抽選・節目のJSON](specs/calculated-traces.json)はseed=0の5本を保存している。これは仕様の算術確認であり、実装の受け入れ検証を代替しない。

## 実装・検証の記録

ゲーム・CLIの実装済み、通常プレイ検証済みの仕様はまだない。実装後は各Sへコードと検証日の根拠をリンクする。現時点で確認したのは分冊の定義、机上計算、参照・表記の整合性である。
