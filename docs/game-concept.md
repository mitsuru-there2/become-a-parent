# ゲーム企画

状態：基本方針は合意済み。具体例は設計案。作成日：2026-09-12。

正式タイトル：**親伝説 — Become a Parent**（2026-09-14、ユーザー指定、D-019）。

## 作品の核

子育てのあるあると予想外の人生を、笑いながら何度も楽しむコメディ・シミュレーション。限られたお金・時間・心の余裕を使い、子どもとの関係を築きながら、家族と自分の長期的な幸せを探す。

プレイヤーは親として半年ごとに意思決定し、0歳から20歳までの育児編を全40ターンで遊ぶ。子どもの才能や気質は最初から数値で分からず、会話や行動を通して理解していく。子育てを終えた後は老後から最期までを自動でたどり、積み重ねた選択がどんな人生を作ったかを振り返る。

問いは「人生の最後に、本当に幸せを感じるのはどういうことか」。子どもの社会的成功だけでなく、関係の質、本人の意思、親自身の人生にも価値を置く。

## 対象プレイヤー

育児経験を問わず、人生シミュレーションとコメディが好きな人を主な対象とする（2026-09-13合意、D-011）。育児の専門知識を前提とせず、生活上の迷い、家族の反応、予想外の結果を楽しめる体験を目指す。

## 参照作品

[Coffee Inc. 2 公式紹介](https://www.sidelabs.com/coffeeinc2/ja/)（2026-09-12確認）を参考にする。条件を読み、複数の資源を配分し、判断の結果を後から確かめる経営シミュレーションの構造を取り入れる。

この企画では、働き方・家計・休息・家族関係が相互に影響する。子どもには本人の意思があり、親の計画通りになることだけを成功としない。UIの再現や素材の流用は企画の目的に含めない。

## 合意済みの基本方針

- 案2のコメディを主軸とし、子育てあるある、波乱やバッドエンド、再挑戦を楽しむ。
- ボードゲームのように、多少の偶然で生まれる馬鹿馬鹿しい結果も楽しむ。親の計画通りにならないこと自体に遊びの価値を置く。
- ビジュアルはモノクロでシュールな方向。ユーザーが挙げた『UNDERTALE』のような雰囲気を目指す。
- 1ターン半年、年2回、育児編は全40ターン。20歳まで進め、その後は老後を自動でたどる。
- 子どもの気質や適性には個人差がある。親は観察と関わりによって理解を深める。
- 生まれつきの傾向、育つ能力、変化する興味、一時的な心身の状態を分ける。
- 親それぞれの資金への貢献、時間、ストレス、健康、仕事の充実を扱う。
- 働き方による影響は、家事分担、支援、関わり方、子どもの状態との組み合わせで決まる。
- 祖父母の資金・時間・健康・人脈・関係性によって、受けられる支援が変わる。
- 完成形では子ども1人でも複数人でも遊べる。最初の試作は1人に限定する。
- 育児編は子どもが20歳になるまで。その後、親の老後から最期まで自動進行する。20歳はゲーム上の区切りとして扱う。
- 親の幸福度を最終評価の中心にしつつ、子どもの幸福と主体性も振り返れるようにする。
- 困難の兆候と、休息・支援・謝罪・関係修復の機会を設ける。

## 偶然と表現

多少の偶然や飛躍した結果を楽しむ方針は合意済み。行動や状態によって結果の候補・確率を変えること、活動とは無関係な珍事が起きることなど、具体的な抽選方式は設計案。すべての出来事を現実的な因果だけで説明する必要はない。選択が影響する部分と、運に任せる部分のバランスを試す。

見た目の合意はモノクロとシュールさまで。黒白の大きな面、簡素な人物、不自然な間、短い台詞といった表現は候補とし、ドット絵、解像度、書体、アニメーションは後の仕様で決める。具体的な登場人物や素材は本作のために設計する。ビジュアル制作はCLIの後に行う。

## ターンごとの体験

観察 → 方針変更 → 出来事への対応 → ターン進行 → 振り返り、を繰り返す。

仕事や習い事などの継続設定は引き継ぎ、「今期は何を変えるか」に集中できるようにする。直後の収支や疲れに加え、数ターン後に分かる関係や成長の変化がある。

隠しパラメータは当てずっぽうにしない。たとえば音楽の適性を数値で示す代わりに、「教室から帰ると自分から曲の話をする」「最近は練習を避ける」といった手がかりを出す。興味、疲労、教室との相性など、複数の可能性を考え、関わり方を変える余地を作る。

## プレイヤーが抱える迷い

- 収入を増やすか、一緒に過ごす時間や休息を確保するか。
- 習い事を続けるか、辞めたいという意思を尊重するか。
- 子どもの挑戦を支えるか、失敗しないよう介入するか。
- 祖父母に助けを頼むか、支援に伴う期待とどう向き合うか。
- 子どもに資源を集中するか、夫婦関係や自分の仕事・友人も大切にするか。

家庭や子どもの状態によって選択の価値が変わり、単一の必勝方針に収束しないことを目指す。

## 困難な結果の扱い

初期構想には、非行、住まいを失うこと、犯罪、失踪、過干渉、虐待などの深刻な展開が含まれていた。これらの具体的な採用範囲は未決とし、小規模試作の必須要件にしない。

採用する場合も、才能を伸ばせないことや共働きから直接発生するルールにはしない。複数の状態と出来事が重なり、途中に兆候と支援の機会がある設計とする。人生の困難そのものを人格の悪さと同一視しない。

ストレスの閾値を一度超えただけで親の人格や結末が不可逆に確定する設計を避ける。制約と影響を段階的に示し、立て直す選択にも意味を持たせる。

## 結末と評価

子どもの社会的成功と親の幸福は同一ではない。「モラル」一つの万能な数値より、思いやり・誠実さ・他者への態度が具体的な行動として表れることを重視する。

親の幸福と子どもの幸福・主体性は分けて示し、食い違いも結末に残す（2026-09-13合意、D-012）。具体的な評価方法はSPEC S-009を正本とする。

最終評価は、親密な関係、生活の安心、自分自身の充実、子どもへの安心感、後悔の5軸を採用する（2026-09-13合意、D-013）。親ごとの差を残す。初版の数式・配点は[SPEC S-009](specs/ending.md)、調整仮説は[Q-014](open-questions.md#q-014初版のバランス仮説)を参照する。

次の3例はいずれも成立させたい結末の設計案であり、固定シナリオではない。

1. 子どもは身近で暮らし、互いに助け合い、孫や家族に囲まれて最期を迎える。
2. 子どもは遠方で自分の道を歩む。孫はいないが、親子の信頼と親自身の友人・地域との関係に支えられる。
3. 子どもは経済的に大成功したが、親子の信頼や他者への配慮が失われ、親は豊かさと後悔の両方を振り返る。

近居、介護、結婚、孫の有無を高得点の必須条件にはしない。関係を修復して幸福に至る人生も扱えるようにする。

## イベント候補

以下は題材の案。効果量、発生条件、選択肢はSPECで具体化する。

| 題材 | 主な判断・観察 |
| --- | --- |
| 習い事を辞めたい | 興味の変化、疲れ、相性を聞き、継続や休止を考える |
| 学校で作った作品を見せてくる | 成果だけでなく本人の関心にどう反応するか |
| 友人とのトラブル | 話を聞く、見守る、学校に相談する判断 |
| 仕事の繁忙期 | 収入、時間、休息、家事分担の調整 |
| 祖父母の援助申し出 | 支援内容と家族の希望のすり合わせ |
| 家族旅行の提案 | 出費と時間、各人の希望の配分 |
| 親の疲労の蓄積 | 休息や外部支援に資源を使う判断 |
| 学校での評価の変化 | 一度の結果をどう解釈し、関わるか |
| 子どもが自分で決めたいと言う | 安全への配慮と自律性の尊重 |
| 言い争いの後の会話 | 謝罪、説明、時間を置くなどの関係修復 |

## 初期開発の焦点

最初から0〜20歳の育児と老後・最期までを通す。PoCではイベントや初期パターンの種類を絞り、シンプルなパターンをいくつか作る。観察から行動を変える面白さ、資源配分、回復、選択が長期的な幸福につながる仕組みを検証する。

パラメータ、イベント、それらのつながりを仕様として具体化した後、ビジュアルなしのテキストベースのゲームを作る。その動作を確認してビジュアル化し、徐々にバリエーションを増やす。基本パターンは共通ルールで条件や選択を比較するための例であり、最初に選んだパターンだけで結末を固定しない。初版の初期値・効果量は[SPEC](SPEC.md)に調整仮値として具体化済み。

開発順序は[開発計画](development-plan.md)、実装する振る舞いは[SPEC](SPEC.md)を正本とする。

半年単位・40ターンを採用した比較経緯は[ターン構成の比較](turn-structure.md)、現行の進行規則はSPEC S-001を参照する。
