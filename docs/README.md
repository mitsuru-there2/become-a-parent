# 文書運用

状態：本リポジトリで採用する運用。作成日：2026-09-12。

## 基本方針

企画・開発計画・SPECを、実装と同じGitリポジトリ内のMarkdownで管理する。会話だけに重要な情報を残さない。最初に人生全体を通す少数のパターンについて詳細仕様を作り、テキスト版PoCで確かめる。今後の機能拡張でもCLIで実装・検証してから必要なUI・ビジュアルを追加する（D-021）。バリエーションごとに仕様を追加し、検証結果を反映する。

## 情報の正本

| 情報 | 正本 | 書かないもの |
| --- | --- | --- |
| 作品の目的、体験、全体構想 | [ゲーム企画](game-concept.md) | 詳細な数式や進捗 |
| 正式HERO、イラストの画風・参照画像・制作指針 | [アートディレクション](art-direction.md) | ゲーム画面の操作仕様や開発進捗 |
| 開発順序、段階の範囲、完了条件、現在地 | [開発計画](development-plan.md) | 個々の挙動の詳細、仕様策定の細かな進捗 |
| P-SPEC内の順序、決め方、ステップごとの進捗 | [仕様策定計画](specification-plan.md) | 確定したゲームの規則や数値 |
| ゲームの規則、データ構造、操作、受け入れ条件 | [SPEC](SPEC.md) | 判断の経緯の長文 |
| 設定の型・構造検査の実装 | [Valibotスキーマ](../src/content/schemas.ts) | 手編集した生成JSON Schema |

| 決定の理由、代替案、変更履歴 | [意思決定記録](decisions.md) | 現行仕様の複製 |

ルートのREADMEは入口と簡単な状況説明に限る。文書間に矛盾が見つかった場合、上表の正本と最新のユーザー指示を確認して修正する。古い記載を都合よく選ばない。

## 状態の表記

- **合意済み**：ユーザーが承認した企画上の方針。実装済みという意味ではない。
- **設計案**：検討・試作のための案。調整や置き換えが可能。
- **実装対象**：振る舞いと受け入れ条件を具体化し、次の実装範囲に含めたもの。
- **実装済み**：対応コードがあり、参照先を示せるもの。
- **検証済み**：受け入れ条件を確認し、確認日・方法・結果を示せるもの。

未決事項はQ、意思決定はD、仕様はS、開発段階はP、仕様策定ステップはSPのIDで参照する。IDは再利用しない。仕様の状態と開発段階の完了状態は別々に管理する。

## 作業の流れ

1. 対象の開発段階と仕様IDを決める。
2. 必要な未決事項を解消する。仮定で進める場合は設計案として条件と検証方法を記す。
3. SPECに入力・処理・出力・受け入れ条件を具体化する。重要な判断の理由は意思決定記録へ残す。
4. 実装と必要な確認を行う。コードと対応する文書は同じ変更単位で更新する。
5. 確認結果を開発計画に残し、仕様の状態と未決事項を更新する。

最初の実装前には、少数の基本パターンについて、育児から老後・最終評価までのパラメータ、イベント、接続条件を具体化する。将来追加する全バリエーションの確定までは求めない。ユーザーが実装を依頼した後は、通常の実装上の判断のたびに承認待ちにせず、既存の合意内で進める。作品の目的や合意済みの範囲を変える場合は、変更内容を明示して認識を合わせる。

## 試作結果の記録

初期は開発計画の検証記録欄に、対象バージョン・条件・操作や方針・結果・次の判断を記す。件数が増えたら `docs/playtests/` に分割してリンクする。失敗した仮説も残す。一般的な育児の正しさとゲームとしての面白さを混同しない。

AIエージェントのテストプレイでは、実行ID、基本パターン、シード、ルール・データの版、操作ログ、最終評価、選択理由、疑わしい挙動の再現手順を記録する。公開情報だけで遊んだ結果と、内部状態を調べたデバッグ結果を区別する。AIによる比較・不具合探索と、人による面白さ・感情の評価も区別して残す。詳細はSPEC S-012を正本とする。

技術選定後、構成説明が必要になった時点で `docs/architecture.md` を追加する。SPECが大きくなったら `docs/specs/` に分割し、`docs/SPEC.md` は索引として維持する。今は空の文書やディレクトリを量産しない。

## 文書変更の確認項目

- 合意・仮定・未決が判別できるか。
- 他文書と矛盾せず、相対リンクとID参照が有効か。
- 次に作る範囲と、後に回す範囲が分かるか。
- 実装済み・検証済みの主張に根拠があるか。
- 数値やルールの変更理由が必要な場合、意思決定記録があるか。
