# GUIの遊び方

## 起動する

macOSはルートの `play-gui.command` をFinderでダブルクリックします。ブラウザが開き、同じフォルダの `my-family.sqlite` に保存されます。CLIの `play.command` と保存先を共有しているので、途中の人生をそのまま続けられます。

任意の保存先を使う場合は、このリポジトリで実行します。

```sh
python3 -m kosodate gui --run ./my-family.sqlite
```

初回は家庭と「偶然の種」を選んで開始します。開始時の候補は `--scenario home-02 --seed 3` のように指定できます。既存保存があるときはその保存を優先し、上書きしません。別の人生を始めるには `--run ./another-family.sqlite` のように新しい保存名を指定します。

## 半年を過ごす

1. 年齢・季節、情景文、子どもや家族の様子を読みます。
2. 4つの方針ボタンか「方針を個別に編集」で今期の過ごし方を決めます。個別編集は「方針を保存」で保存します。プリセットや補助ボタンはその場で方針を保存します。
3. 出来事の選択肢をクリックします。「選択中」が保存された回答です。確定前なら選び直せます。
4. 収支予測・時間・世話の配分を確認します。未回答や不足があると確定できず、理由が表示されます。年代や支援を変更したら「世話の配分を合わせる」が使えます。
5. 「この方針で半年を進める」を押すと、結果を表示して次の期へ進みます。40期目の確定後は、老後から最期までをたどった結末を表示します。

「基本の配分にする」は公開された基本案を入力する補助です。休息や関わりを減らすため、普段の推奨方針ではありません。適用後も出来事の回答と確定条件を確認してください。配分の効果は[CLIガイド](cli-guide.md)と[S-002・004](specs/core.md)を参照してください。

「振り返り」でこれまでの半年と老後の記録を読めます。各記録をクリックすると本文・収支・当時の観察や方針が開きます。結末では親それぞれの幸福・5軸と、子どもの幸福・主体性・社会的成果を分けて表示します。

## 中断・再開

「保存済み」と出たらブラウザを閉じて構いません。サーバーも止める場合は、起動したターミナルでCtrl+Cを押します。同じ起動方法で保存を再開できます。個別編集の未保存変更は「方針を保存」を押すまで残りません。

通信が途切れた場合は「同じ操作を再試行」を使います。確定を二重適用しない仕組みをCLIと共有しています。別のタブやCLIから同時に変更した場合は競合を表示するので、「保存済みの状態を読み直す」で最新状態を開いてください。

## 接続と必要環境

Godot・Pythonの必要環境は[README](../README.md#必要環境)を参照。追加パッケージやインターネット接続は不要です。GUIはこのパソコンの127.0.0.1内だけで通信します。

ブラウザが自動で開かなければ、ターミナルに表示されたURLを開きます。既定では空いているポートを選びます。自動起動を省略したい場合やポートを固定したい場合：

```sh
python3 -m kosodate gui --run ./my-family.sqlite --port 8765 --no-browser
```

固定したポートが使用中なら、`--port` を外して再起動してください。スマートフォン幅の表示にも対応しますが、別端末へのネットワーク公開は行いません。
