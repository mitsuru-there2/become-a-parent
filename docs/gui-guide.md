# ブラウザ版の遊び方

[README](../README.md)の手順で起動し、表示されたURLを開きます。新方式の正本は[S-016](specs/decisions.md)。

1. 家庭・難易度・シードを選び「新しい人生をはじめる」。
2. 期首の特殊イベントに対応します。選択すると即時確定します。対応を選ぶまで通常の判断へは進めません。保存一覧へ戻って中断できます。
3. 年齢や状況に応じた3つの判断で、それぞれ1つ選びます。「何もしない」も回答です。一件ずつ表示され、下の「判断1〜3」から半年を進めるまで選び直せます。
4. 半年の見通しを確認し「半年を進める」。3件の未回答や資金不足があれば進めません。

父母の能力によって成果と負担が変わります。「家族の様子」は5段階の一言で表示します。危機の間は立て直せますが、離婚・一家離散が発生するとゲームオーバーです。通常は40期を終えると子どもが20歳になり、その後は父母の老後・最期・結末まで進みます。

選択は都度このブラウザへ保存されます。「何もしない」を選んでも生活費や現在の継続費用は発生します。入園先などを変更すると、予測には変更後の継続費用が反映されます。

「家族の記録」で出来事、3つの判断、収支、家族の変化を振り返れます。途中終了した記録も残ります。「遊び方」内の「書き出し」でJSONを保存し、別のブラウザでは保存一覧の「保存ファイルを取り込む」で再開できます。同IDの上書きはしません。

中央には現在、共通のダミーカット絵を固定表示しています。「家族の様子」で能力・疲労・子どもの観察・前期結果を確認できます。画面全体は固定し、長い記録や小さい画面では本文欄の中をスクロールします。

## 以前の保存

save-2・save-3は以前の配分方式で再開します。新方式は新しく始めた人生に適用します。旧方式では「今期の方針」を編集して保存し、イベント回答後に半年を進めます。時間配分や未保存フォームの扱いは従来どおりです。

## 難易度と追加シナリオ

難易度・追加パックは開始時に固定します。新方式では追加行動も3つの判断の選択肢に入り、追加イベントは条件を満たすと特殊イベントの候補になります。開始時の設定を保存するため、後の設定更新で進行中の人生のルールは変わりません。

購入機能は後続です。設定方法は[設定ガイド](../config/README.md)。
