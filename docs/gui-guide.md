# ブラウザ版の遊び方

[README](../README.md)の手順で起動し、表示されたURLを開きます。

1. 家庭とシードを選び「新しい人生をはじめる」。保存済みの人生は「つづきから」で再開できます。
2. 子どもの様子を読み、出来事への回答を選びます。
3. 「今期の方針」で各親の配分・活動・支援を編集して保存します。4つの方針案や世話の配分補助も利用できます。
4. 「半年の見通し」に出る不足理由を解消し「半年を進める」。40期の後は老後・最期・結末まで進みます。

方針や回答は半年の確定前なら変更できます。画面の未保存の編集は「方針を保存」で保存し、または「編集を取り消す」で戻します。予測は保存済みの案に対応します。各親の時間は12単位、世話は必要量ちょうどです。

「家族の記録」で過去の出来事・観察・配分・収支・成人後を振り返れます。「遊び方」はゲーム中にも開けます。これらの画面に切り替えたり、出来事に回答したりしても、未保存の方針は保持されます。方針の数値入力からEnterキーでも保存できます。

保存はこのブラウザ・このサイトに保持されます。ブラウザのデータ削除で消えるため、「書き出し」でJSONを手元に残せます。別のブラウザ・端末・公開サイトへは、保存一覧の「保存ファイルを取り込む」で移動します。同IDの上書きは行いません。

別タブの更新と競合した場合は、編集を取り消し「最新の保存を読み直す」を使います。保存失敗時も編集中の値は残ります。理由を確認して再保存するか、編集を取り消して読み直してください。

## 難易度と追加シナリオ

開始画面で「やさしい」「ふつう」「むずかしい」を選べます。登録されている追加パックがある場合は、追加シナリオのチェック欄と家庭が表示されます。追加行動は「今期の方針」で選び、通常の方針と同じように保存します。費用と担当親の時間を消費し、対象外の時期は選べません。難易度・パックはその人生の開始時に固定します。新規保存では使用設定も保存するため、設定ファイルの更新で途中のバランスが変わることはありません。

DLCの購入機能は後続です。登録例と設定方法は[設定ガイド](../config/README.md)。
