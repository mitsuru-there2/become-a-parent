# ブラウザ版の遊び方

[README](../README.md)の手順で起動します。新規ゲームの正本は[S-018](specs/selection-tree.md)。

1. 難易度を選び「新しい人生をはじめる」。家庭は標準、追加パックはなしで開始し、偶然を決めるシードは自動で生成されます。
2. 期首に出来事があれば、最大3件のダイアログが約300ms間隔で手前に重なります。手前から一件ずつ読み、「閉じる」で次へ進みます。イベントへの回答は不要です。
3. そのまま進めるなら「この暮らしで半年進める」。何も選ばなくても、現在の生活と日常の休息・学びが続きます。
4. 必要なときだけ教育・進路、家庭生活、実家、遊び・放課後、仕事・家計を開いて変更します。

継続する設定は変更するまで続き、今期だけの行動は実行後に終了します。単発行動は全分類合計2件まで。予定は自動保存されますが、半年を進めるまでは費用や効果を適用せず、「この予定を取り消す」「今期の予定をすべて取り消す」で戻せます。支出は生活費・変更後の継続費・変更時の開始費を含みます。資金不足や行動枠超過は進める前に表示します。

選択すると、次の期から新しい選択肢が現れます。例：工作教室を体験 → 次期に入会 → 通い続ける間に発表会や休会。新しい内容は「今期の機会」にまとめます。何も選ばなくても続けられ、全メニューを毎期開く必要はありません。卒園などで対象期間を終える設定や、実家の支援条件を失う設定は標準へ戻り、理由を表示します。

「家族の様子」で父母の能力・疲れ、祖父母、子どもの観察を確認できます。「暮らしの一覧」には前の半年の振り返りもあります。家族の危機は回復できますが、離婚・一家離散が成立すると途中終了です。通常は40期で子どもが20歳になり、父母の老後・最期・結末まで進みます。

「家族の記録」で出来事・生活・行動・収支を振り返れます。「遊び方」の「書き出し」で保存JSONを持ち出し、別のブラウザの保存一覧から取り込めます。同じIDの保存は上書きしません。

プレイ画面のマップでは子ども・父・母・実家を下部に表示し、タップすると各人の詳しい状態を開けます。スマホでは肖像と主要3値の小さな図だけを短いバーに並べ、判断カテゴリを開くと専用画面に移ります。専用画面ではステージとルートを切り替え、判断カードから詳細と取得確認を開きます。半年進行はマップへ戻って操作します。

中央のマップから5分類へ進みます。PCは横長、モバイルは縦長の地図です。モバイルの判断専用画面は1ルートずつ全幅で表示し、カード一覧を縦にスクロールします。最初の岐路では未選択カテゴリに「ルートを選択」が出て、全ルートを確定するまで半年進行ボタンは使えません。後続の岐路では、変更できるカテゴリに「ルート変更可」が出ます。変更せずに半年を進めることもできます。

## 以前の保存と追加パック

save-2〜8は、その人生を始めた時の操作とルールで再開します。新しいメニュー方式はsave-9からです。難易度・パック・設定は開始時に固定し、後からの設定変更で進行中の人生を変えません。

「地域の創作活動」はDLC拡張の開発用サンプルです。スタートページからは選択できません。共通サービスやCLIで指定したゲームだけに工作会と関連イベントが加わります。購入機能は未実装。追加方法は[設定ガイド](../config/README.md)を参照してください。
