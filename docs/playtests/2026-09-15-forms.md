# TanStack Formへの移行検証

2026-09-15。[S-013](../specs/gui.md)・[D-026](../decisions.md#d-026フォームにtanstack-formを原則使用する)。TanStack Form 1.33.5、既存のReact・Valibot・共通サービスを使用。フォームのUIリファクタリングであり、エンジン・CLIの操作契約は変更していない。

## コンポーネント・内部状態の検証

[テスト](../../tests/forms.test.ts)はjsdomとTesting Libraryで実際の入力・送信を操作する。内部状態を検査する技術検証であり、公開情報だけのテストプレイとは区別する。

- 1項目（親Aの休息）の変更で当該入力だけを再描画し、他の14入力の描画回数が増えない。入力部品の呼び出しを計数し、TanStack Form自体は実物を使用。元の値に戻すと未保存フラグが解除される。
- 活動と強度の相互補完、プリセット、編集取消が動作。補完の初回検証で見つかった同値更新の再帰を、変更が必要な場合だけ更新することで修正した。
- 出来事への回答で未保存入力を保持。方針保存成功後は保存値が取消の基準となる。
- 不正な空欄と保存失敗でも編集を維持。前期への復帰で基準値を更新。
- 新規開始で難易度・シードを送信。送信中の重複実行を抑止。
- 取り込み失敗後に同じファイルを再選択して再試行できる。

`bun run test`：6ファイル・46テスト成功（うちフォーム6件）。`bun run check`：生成JSON Schema一致・書式・lint・型検査成功。

## 公開操作によるブラウザ検証

[ブラウザ検証スクリプト](../../scripts/browser-check.ts)をChromeで実行。`GAME_URL=http://127.0.0.1:5174 BROWSER_ARTIFACTS=/tmp/parent-form-check bun run test:browser`。このスクリプトは画面の公開情報のみを使用し、ストア・IndexedDB・隠し状態を判断に使わない。

- 基本の家庭、シード0、むずかしい。未保存編集を保持したまま回答し、遊び方→家族の記録→いまの暮らしを往復して取消できた。
- Enterキーで方針保存。未保存中の半年進行禁止、保存後の解除を確認。
- 「好きに付き合う」を基本とし、未回答の出来事は表示された最初の選択肢で回答。全40期から結末「それぞれの予定表」まで到達。
- 再読込、48件の全履歴、書き出し、別ブラウザコンテキストへの取り込みで結末を維持。
- 1280px・390px幅の画面を保存・目視確認。390pxで横溢れなし。ブラウザの警告・エラーなし。
- 画像と操作記録は`/tmp/parent-form-check/`に出力（ローカルの一時成果物）。

## ビルドと検証の限界

`bun run build`成功。JavaScript 716.89KB、gzip 224.64KB。直前の構成は655.23KB、gzip 209.59KBで、今回のフォーム依存・実装追加でgzip約15.05KB増加した。既存の500KBチャンク警告は残る。

検証した改善は購読範囲と再描画回数であり、端末ごとの入力遅延やFPSの比較測定ではない。追加パック未登録の本編でブラウザ検証を実施した。DLCのゲーム規則・保存互換は既存の共通エンジン・サービスのテストで確認する。
