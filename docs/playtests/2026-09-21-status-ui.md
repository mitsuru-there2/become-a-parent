# 子ども・家族の常時表示の検証

2026-09-21。対象：[S-018 / AC-018-E](../specs/action-tree.md)、[S-003](../specs/core.md)、D-058。実装・機械検証済み。人による分かりやすさの評価はQ-014に残す。

## 結果と変更

子どもの公開観察を上部、父母・実家と進行操作を下部に分離した。PCは全項目、モバイルは主要項目と詳細パネルを使う。マップは道とアイコンの座標を共有し、横長・縦長の比率を維持する。低い画面は中央領域内のスクロールを許し、家族・操作を覆わない。

短文は共通エンジンが既存の観察区分から公開応答専用に生成する。保存の観察・履歴を変更しない。旧コンテンツに短文がない場合、UIは既存本文を表示する。

## 環境

- URL：`http://127.0.0.1:5174`。5173が使用中だったため開発サーバーが選択したポート。
- Chrome / Playwright。Browser plugin not availableのため、既存のPlaywrightスクリプトを利用。Chrome起動はサンドボックス内で失敗したため、許可されたサンドボックス外実行で検証した。
- 必須：1440×900、1024×768、390×844、320×568、844×390。
- 追加：1600×760、1280×900、1280×720、1026×760、1024×600、789×760、641×600、360×640、320×480。

## 公開UIの検証

検証フロー：新規開始 → 出来事を閉じる → 子ども・家族の表示 → 5分類 → 詳細・確定・取消 → 半年進行 → 40期・成人後・結末 → 保存の書き出し／取り込み。

| 確認 | 結果 |
| --- | --- |
| ページ識別・空白画面でないこと | 親伝説のタイトルと地図を確認 |
| フレームワークエラー画面 | なし |
| console error/warning・pageerror | 0件 |
| 14サイズの配置 | 外側の縦横スクロールなし、道とアイコン一致、下部操作との可視領域の重なりなし |
| 必須5サイズの分類操作 | 各サイズで5分類すべてを開き、地図へ戻れる |
| 家族の常時表示 | 父・母・実家の3列が画面内に存在。全員の詳細を開閉できる |
| キーボード | 詳細内にTabフォーカスを保持し、Escapeで閉じると元のボタンへ復帰 |
| 子ども詳細 | 観察全文を表示し、閉じた後も選択中の分類ツリーを保持 |
| 家計 | 資金の予定と内訳をダイアログで確認 |
| 進行・保存 | 40期、成人後、結末、再読込、書き出し・取り込みに成功 |
| 既存分岐 | DLC、体験・入会・休会・再開、予定取消、別プレイの離婚を確認 |

既存の検証スクリプトの旧フローティング配置に関する判定を、新しい専用領域・44px以上の操作・クリップ後の可視領域の判定へ更新した。320×480や横向きでは中央のスクロールを使う。隠れた要素の未クリップ座標を、下部との見た目の重なりとは扱わない。

## 内部検証（公開プレイとは別）

- `bun run test`：16ファイル、111件成功。全年代の代表点で短文の観察区分・非数値化を確認し、公開応答生成前後で保存状態が変わらないこと、旧本文へのフォールバックを検証。既存の40期・保存・再生テストも成功。
- 進行不可のUIテスト：資金不足の公開応答に対して理由ダイアログを表示し、`advance`を送信しない。
- CLI `new`：`/tmp/parent-status-cli` の専用保存で、公開観察の `short_text` と本文の返却を確認。
- `bun run check`：整形、lint、型、JSON Schema、コンテンツ検査成功。
- `bun run build`：SPA生成まで成功。約606 kBの画面チャンクにサイズ警告あり。分割最適化は今回の範囲外。
