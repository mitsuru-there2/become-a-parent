# S-013：CLIに対するGUI

2026-09-14。状態：実装済み・技術検証済み。方針はユーザー指定（D-021）。実装は[GUI接続](../../kosodate/gui.py)・[画面](../../kosodate/web/app.js)、根拠は[GUI検証記録](../playtests/2026-09-14-gui.md)。人による面白さ・操作負担の評価は未実施。

## 境界と開発順序

ゲーム開発は仕様 → CLIの共通処理・データ → CLI検証 → 必要なUI・ビジュアルの順に進める。GUIはS-011の公開コマンドを操作するクライアントであり、ゲーム計算、抽選、確定条件、保存形式を持たない。CLIと同じ `Service.execute` を呼び、同じSQLiteを相互に再開できる。隠し状態、debug-state、非公開GodotブリッジはGUIから利用しない。

初版はPython標準ライブラリのローカルHTTPサーバーとHTML/CSS/JavaScript。`python3 -m kosodate gui --run 保存先` とmacOSの `play-gui.command` でブラウザを開く。外部通信・追加パッケージを必要としない。サーバーは127.0.0.1だけにバインドし、指定の保存先だけを扱う。既存保存を上書きして新規作成しない。

## 画面と操作

- 未作成時は開始画面で家庭・シードを選ぶ。既存保存は自動で再開し、終了済みなら結末を開く。
- 育児画面は年齢・季節・進捗、情景と公開観察、家計・家族の公開状態、今期の方針、出来事、予測と確定操作を表示する。
- 情景は公開されている年代・季節だけに基づく演出文。子の隠れた気質・適性・未来の結果を推測しない。公開観察と出来事本文はCLI出力をそのまま使う。情景表示は独立モジュールとし、後から画像表示を足せる領域を持つ。
- 方針の4プリセットはCLI対話版の入力補助を共有する。各親の仕事・世話・関わり・休息・自分の時間、活動・担当・関わり方・支援を日本語で編集できる。値域・選択値はactionsから取得する。フォームは「方針を保存」でplanを送り、未保存中は半年を確定できない。
- 世話の配分補助、前期の方針へ戻す、公開forecastの無理のない案を適用する入力補助を設ける。回答と方針は半年を確定するまで変更可能。回答・保存だけでは時間を進めない。
- 時間・世話・収支はforecastを表示し、不足理由を明示する。選択肢の費用・入金・配分調整の必要性を表示する。未回答・資源不足時は確定ボタンを無効にする。未対応イベントも返されたchoicesから表示する。
- 確定後は直前の半年の結果を次期の情景と分けて残す。40期後は親別の5軸評価、子どもの幸福・主体性・社会的成果、結末、老後を含む全履歴を読める。
- 履歴・遊び方はいつでも開ける。保存成功を表示し、閉じるときに未保存のフォームがあればブラウザの警告を出す。保存済みの方針・回答は再読み込みで復元する。
- 処理中は更新操作をロックする。revisionとrequest-idはS-011に従う。通信結果が不明な場合は同一request-idで再試行できるよう入力を固定する。別のCLI・タブが更新した場合は競合を表示し、最新状態を読み直す。
- 小さい画面では縦並びとし、キーボード操作、ラベル、フォーカス表示、減らした動きの設定に対応する。

## 受け入れ条件

- AC-013-A：ブラウザから新規開始・方針編集・選択・確定・履歴閲覧・保存再開・終了済みの振り返りを行える。40期と老後・結末まで到達できる。
- AC-013-B：GUI経由の同じ入力とCLIの公開応答・最終評価が一致し、GUIの保存をCLIで再生すると全40期が一致する。内部状態を見るデバッグと公開プレイ検証は区別する。
- AC-013-C：未回答・資源不足・古いrevision・無効入力・通信再送で二重進行しない。失敗理由と復旧操作を画面から利用できる。
- AC-013-D：GUIの通信に隠し状態が含まれず、任意ファイル指定やdebug-stateの実行を拒否する。外部Origin、誤ったHostやセッショントークンを拒否する。
- AC-013-E：デスクトップと狭い画面で情景・選択肢・確定操作が読め、画像なしでゲームを進められる。画像用の表示拡張がゲーム処理の変更を要しない。
