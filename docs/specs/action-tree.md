# S-018：計画できるアクションツリー

2026-09-18、D-039。ユーザー指定に基づく実装契約。S-017の非表示分岐とD-035の祖父母個別化を新規ゲームで置き換える。rules-9 / data-9 / save-10。旧保存は元の設定とルールを維持する。

- 全分類・全年齢・取得済みを含めたツリーを常時参照できる。線と前提名で枝のつながりを示し、未解放も詳細を開ける。取得条件は年齢、確定済みの履歴、現在の方針、年収、成績、親や実家の数値、費用。予定だけでは後続を解放しない。
- 年収は基本半年収入と確定中の有効な継続方針による収入の合計の2倍。減収方針は設定のincome_reductionを差し引く（家計計算では既存のcostに含め、重複控除しない）。臨時収入は年収に含めない。成績は学び能力0〜100を公開し、隠し適性は開示しない。
- 各選択は即時／毎期の効果に加え、イベント結果の数値効果への補正を持つ。good/bad別の百分率を加算し、合計を−80〜+200%に制限。小さい効果にも変化が出るよう絶対値を四捨五入し、端数によって消える差は補正方向に1点動かす（最小0）。確率は変えない。資金移転（援助資金を含むイベント）は金銭効果を補正せず、有限の財布を維持する。
- 継続方針の補正は対象年齢・維持条件を満たして継続中のみ。単発行動の取得効果は確定の次期から育児終了まで有効、繰り返しても重複取得しない。未確定予定・取消は効果を持たない。後段ほど強い利点と負担を対にする。補正値と由来を選択前とイベント結果に示す。
- 4歳から保育所、6歳から公立小学校を無料の既定経路とする（基本生活費に含む）。私立・インターナショナルは見学、年収、成績、資金を条件とする。小学校は12歳で終了。後段に受験準備、進学、大学準備の枝を設け、年代を越えて計画できる。年齢条件・切替の排他・継続費・既定対応を事前表示する。実在の入学制度を再現するものではない。
- 実家は体力8、関係6、援助資金100万円、地域のつながりありの一つの仲間。新規ゲームには個人別状態を持たせず、援助・疲労・回復・維持条件も共通値を使う。
- メイン画面は上部の子どもの様子、中央のマップ／分類ツリー、下部の家族状態と操作に分割する。5分類は家庭生活を中央、教育・遊びを上段、実家・仕事を下段へ均等配置する。道とアイコンは共通座標を使い、PCは横長、640px以下は縦長の比率を維持する（D-058）。
- 地図の横幅は1000pxまでとし、絵を縦横に引き伸ばさない。分類名を常時表示し、分類ごとの件数は表示しない。予定がある分類だけ「予定中」を表示する。分類画面の見出しは分類名と説明を表示し、英語の補助見出しとアクション件数は表示しない。
- ツリーには実行できる内容ごとに独立したノードを表示する。ノードを選ぶと詳細ダイアログが開き、内容・取得条件・費用・効果を確認して「このアクションを確定」または「キャンセル」を選ぶ。ダイアログ内に別の実行案の選択肢は置かない。予定済みのノードは同じダイアログから取り消せる。方針間の排他と既定経路は既存の判定を使う。
- 各実行案には任意の`visual` IDを設定でき、共通`visuals`から画像を解決する。未設定のアクションは暫定的に`hero`を表示する。個別のビジュアル制作は後でまとめて行う。
- 「現在の暮らしと取得効果」はメイン画面に置かず、家族の様子タブで現在の方針と有効な効果を表示する。
- 画面は100dvh内に収め、上部と下部を常時表示する。分類ツリー・履歴など中央のみ内部スクロールする。極端に狭い・低い画面では地図も内部スクロールを許し、44px以上のタップ領域を維持する。
- マップの操作を繰り返し説明する文と、予定がないことを説明する文は表示しない。今期の予定がある場合だけ、予定内容と一括取消をマップ下に表示する。
- 操作は下部の専用領域に置く。1024px以上では家族状態の右、未満ではその下の横一列とし、進行を強調する。進行不能時は確定させず、同じボタンから理由を開ける。右上の資金と予測内訳は維持する。家族はPCで全項目、1024px未満では父母の健康・疲労・ストレスと実家の体力・関係・援助資金を常時表示し、タップで詳細を開く。子どもは疲れ・父母それぞれとの関係・両分野の興味を短文で表示し、観察全文は詳細に置く。詳細はモーダルで背景を操作不可にし、終了後は元の操作へフォーカスを戻す。

受け入れ条件：

- **AC-018-B**：補正の継続／解除／履歴取得、強弱、善悪別の加算・上限・数値上下限・援助総額を検証。イベント結果に適用元を残す。
- **AC-018-C**：無操作で4歳と6歳の既定経路に入り、私立等と排他になり、卒業後の費用と効果が残らない。
- **AC-018-D**：実家の共通状態、有限援助、回復、保存再開・再送・再生一致と40期・成人後の完走を確認。旧rules-8の分岐・再生を維持。

## 年代と選択で育つ物語（2026-09-18、D-040）

実装対象：本編の既存ツリーへ、幼児の見立て遊び・タイムカプセル、科学と発明、音楽、スポーツ、家族の冒険、実家の料理と屋台、親の独立、若者の進路と巣立ちを追加する。本文・費用・分岐の正本は`config/decisions.json`、出来事は`config/events.json`。ゲーム上の誇張であり、実在の教育・起業・競技制度を再現しない。

- 入口から継続・挑戦・後年の振り返りへ、年齢と確定済みの選択をつなぐ。既存の工作体験・科学体験・進路相談・実家訪問・働き方相談も新しい枝の入口にする。
- 挑戦だけを正解にしない。同じ行動の中で、少額の身近な体験、費用と疲労を伴う大舞台、休止や方向転換を選べる。単発の大きな賞金は一度限り、継続活動には無料の終了設定を置く。未確定の予定や取消では後続・専用イベントを解放しない。
- 選択専用イベントは、履歴だけでよい思い出と、活動中だけ起きる出来事を分ける。大舞台へ挑んだ後にも必ず入賞するとは限らず、成功・珍事を独立抽選する。本文は努力と結果のつながりを示す。自動イベントへの必須回答は増やさない。
- 年代限定の珍事と一度限りの節目を増やし、既存の全年齢イベントの頻度も調整する。独立抽選・ID別の乱数・再発間隔は維持し、標準生活の複数シードで平均1〜3件/期を目安に検証する。毎期の件数保証ではない。
- 設定追加のみでrules-9 / data-9 / save-10を維持する。同一版内の内容は保存済み設定とfingerprintで識別し、既存の人生には追加内容を注入しない。

受け入れ条件：

- **AC-018-F**：異なる選択から異なる後続行動・専用イベントへ進む。幼児期の選択が後年に再登場し、前提なし・対象年齢外・取消・休止中に専用の展開が漏れない。各追加分岐の選択肢を通常の確定操作で取得できることを確認する。
- **AC-018-G**：年齢別イベント、専用イベントの一度限り・再発間隔、同一シードの再現と異なるシードの変化を確認する。3難易度の標準生活で40期と成人後に到達し、平均頻度と最頻イベントを記録する。
- **AC-018-H**：公開CLIで複数の新規経路を0〜20歳・成人後まで進め、保存再開・再送・再生で予定・取得・イベント・収支が一致する。旧設定の保存は新しいカタログで開いても変わらない。人による飽きにくさ・面白さの評価はQ-014で継続する。

## 大ルートと学校の4系統（2026-09-21、D-063）

HoI4のナショナルフォーカスツリーを参照し、選択した道、次の目標、分岐の代価を一画面で読めるようにする。添付画像は情報配置と接続線の参考であり、画像内の政治・軍事題材やルールは本作へ取り込まない。新規ゲームはrules-10 / data-10 / save-11を使う。数値はゲーム調整の仮値で、実在の就学制度や子育ての効果を表さない。

### 階層と学校ルート

- 5分類（家庭生活、教育・進路、遊び・放課後、実家、仕事・家計）を大きな入口として残す。排他は分類同士ではなく、各分類の中で互いに両立しない**長期方針のルート群**に付ける。D-063で教育・進路の「学校」を4ルート化し、D-065でほかの4分類へ広げる。分類同士は並行して利用できる。
- 学校ルートは`public`（地域の園・公立）、`private`（私立）、`international`（インターナショナル）、`home`（自宅学習）の4本。4〜5歳の園、6〜11歳の小学校、12〜14歳の中学校、15〜17歳の高校にそれぞれノードを置く。18〜19歳の進路準備は4本の実績から接続する合流領域とし、特定ルートだけが結末に到達できる構造にしない。
- 各段階の先頭は「所属先」の継続方針、その先にルート専用の単発行動を1つ置く。公立は地域の活動、私立は校内の探究、国際は共同制作、自宅は地域との接点。追加の枝は学校所属だけで自動取得されず、年齢、過去の確定、能力、費用などを満たして選ぶ。各ルートに利点と負担の両方を設定する。18歳以降は各ルートの高校履歴から進路を考える単発行動へつなぎ、共通の進路アクションも利用できる。
- 4歳の無操作では現行どおり保育所、6歳の無操作では公立小学校。園・小・中・高の境界では、継続条件と家計を満たす限り直前のルートを次段階へ引き継ぐ。引き継げない場合は無料の地域・公立経路に戻し、理由を事前と結果に表示する。自動復帰では現金の切替費を課さず、ルート専用の継続効果を終了する。自宅学習からの自動復帰も同じ扱いとし、進行を止めない。

| 段階 | 公立・地域 | 私立 | インターナショナル | 自宅学習 |
| --- | --- | --- | --- | --- |
| 園・4〜5歳 | 保育所（既定） | 私立幼稚園 | インターナショナル園 | 家庭で学ぶ |
| 小・6〜11歳 | 公立小学校（既定） | 私立小学校 | 国際系小学校 | 自宅学習・小 |
| 中・12〜14歳 | 公立中学校（既定） | 私立中学校 | 国際系中学校 | 自宅学習・中 |
| 高・15〜17歳 | 公立高校（既定） | 私立高校 | 国際系高校 | 自宅学習・高 |

### ルート転換の代価

- 同じルートで進級する場合は切替ペナルティーを課さない。別ルートへ移る場合は、同じ段階の途中でも段階の境界でも「進路の切替準備」を1件の単発行動として確定する。初めて4歳の園ルートを選ぶ際は転換とみなさない。取得予定の取消、未確定のプレビューでは代価を取らない。
- 切替準備の調整仮値は**80万円、今期の単発行動枠1件、半年進行の確定時に子どものストレス+3**。準備を実行した次期だけ新ルートの所属先を選べる。準備期は旧ルートを継続する。新ルートの通常の入学・開始費は別途必要で、画面とCLIの予測にはそれぞれの適用時期と金額を出す。準備後に新ルートを選ばず期限を過ぎた場合、準備費は返らず、ストレスも自動で取り消さない。次期に学校段階が存在しない時期は準備できない。費用なしの立て直し行動と無操作での既定進行を維持する。
- ルート移行後は旧ルートの**継続**効果と専用イベントの継続条件を終了する。確定済みの単発行動の履歴は消さないが、新ルートの専用枝を自動解放しない。同一期に二つの学校方針や複数の切替準備を確定できない。条件不足・資金不足なら準備や移行を拒否し、不足理由を公開する。
- 切替の大きさは比較プレイで調整する。無操作、公立→私立、私立→国際、国際→公立、自宅→公立と、同じルートを続けた場合を比較し、転換が実質無料にも回復不能にもならないことを確認する。費用を払えない場合の無料既定復帰と、予定の取消を検証する。

### 表示と実装の境界

- 教育・進路を開いた画面では、列を公立・私立・インターナショナル・自宅学習、行を園・小・中・高・18歳以降として固定する。年代とルート内の前提は上から下へ進み、進級を縦の実線、ルート間の転換口を段の境界の横向き破線で示す。ほかの分類の前提ツリーも下向きに進む。現在のルート、取得済み、予定、条件待ち、切替費を区別する。全ノードと将来の条件を閲覧できる。モバイルでは縦方向に年代をたどり、横方向にルートを切り替えられる。開いたときは現在の段階とルートへ移動する。ノード詳細の確定・取消、上部の子どもと下部の家族・進行操作を維持する。
- ルートID・所属段階・切替先と効果は設定データで定義し、判定と予測を共通エンジンで行う。Reactには配置と公開状態の描画だけを置く。追加パックでも同じ参照検査を通し、未知のルートや循環、同一段階の重複、既定経路の欠落を拒否する。既存保存は開始時の設定と旧ルールのまま再生する。

受け入れ条件：**AC-018-J** 全4ルートが園から高校・18歳以降まで表示され、無操作で既定の人生を完走できる。**AC-018-K** 同ルート進級は開始費なし、別ルートへの移行は前期の準備と費用・状態変化を一度だけ計上し、取消・資金不足・準備の失効で誤取得しない。**AC-018-L** CLIとUIの所属・準備・条件・予測が一致し、保存再開・再送・再生、旧版、追加パック、モバイルの閲覧とフォーカス移動で整合する。学校以外の4分類は並行して使える。

## 5分類の縦型大方針（2026-09-21、D-065）

新規ゲームはrules-11 / data-11 / save-12。D-063の学校ルートを維持し、家庭生活・実家・遊び・放課後・仕事・家計に大方針を追加する。各分類の方針は独立して選べる。旧保存のrules-9と学校のみのrules-10は当時の設定で再生する。

| 分類 | 大方針 | 無操作の既定 | 切替準備の費用・負担 |
| --- | --- | --- | --- |
| 家庭生活 | 日常を整える／思い出を残す／家族で冒険する／自立を支える | 日常を整える | 70万円、子どものストレス+2 |
| 実家 | 交流を続ける／預かりを頼む／料理と思い出を継ぐ | 交流を続ける | 65万円、子どものストレス+2 |
| 遊び・放課後 | 工作・科学を楽しむ／音楽を育てる／スポーツに挑む | 工作・科学を楽しむ | 70万円、子どものストレス+2 |
| 仕事・家計 | 家族時間を守る／仕事で責任を担う／自分たちの店を育てる | 家族時間を守る | 80万円、父のストレス+2 |

- 大方針は0歳から19歳まで続く1件の継続方針。初回は任意の枝を無料で選べる。無操作なら表の既定ルートで進む。各ルートに既存の物語・支援・継続方針を割り当て、交流の便り・仕事の分担や研修など枝が少ない箇所には専用行動を加える。共通の生活方針・相談・臨時仕事・実家訪問などは別ルート中でも利用できる。初回選択前は既定ルートの専用行動を利用できる。
- 専用の行動・継続方針は、所属ルートまたはその期に確定予定の新ルートが一致するときだけ選べる。別ルートへ移るには前期に分類別の「切替準備」を単発行動枠1件として確定する。準備の次期だけ新ルートを選択でき、未使用なら失効する。資金・行動枠・状態変化は学校と同じ予測・確定処理を使う。転換時は旧ルート専用の継続方針を無料の既定へ戻し、確定済みの単発行動履歴は残す。
- 表示は分類ごとに大方針を横の列、0〜3歳・4〜7歳・8〜11歳・12〜15歳・16〜19歳を縦の段とする。各列は下へ伸び、共通行動の列と切替準備の領域を持つ。どの年齢でも将来の枝と条件を見られる。開いたときは現在の段階と所属ルートへ移動し、切替準備へ直接スクロールできる。狭い画面はツリー領域内で縦横にスクロールする。

受け入れ条件：**AC-018-M** 全5分類に大方針の列があり、専用枝・共通行動・条件・切替費を表示する。**AC-018-N** 別枝への移行は前期の準備だけで成立し、準備の失効・取消・資金不足・旧ルートの継続効果終了が予測と確定結果で一致する。**AC-018-O** 無操作と既存の物語経路が成人後まで完走し、保存再開・再生、rules-9・10の旧設定、PC・モバイルの閲覧が成立する。費用・効果の面白さは人のプレイで評価する。
