# S-018：計画できるアクションツリー

2026-09-18、D-039。ユーザー指定に基づく実装契約。S-017の非表示分岐とD-035の祖父母個別化を新規ゲームで置き換える。rules-9 / data-9 / save-10。旧保存は元の設定とルールを維持する。

- 全分類・全年齢・取得済みを含めたツリーを常時参照できる。線と前提名で枝のつながりを示し、未解放も詳細を開ける。取得条件は年齢、確定済みの履歴、現在の方針、年収、成績、親や実家の数値、費用。予定だけでは後続を解放しない。
- 年収は基本半年収入と確定中の有効な継続方針による収入の合計の2倍。減収方針は設定のincome_reductionを差し引く（家計計算では既存のcostに含め、重複控除しない）。臨時収入は年収に含めない。成績は学び能力0〜100を公開し、隠し適性は開示しない。
- 各選択は即時／毎期の効果に加え、イベント結果の数値効果への補正を持つ。good/bad別の百分率を加算し、合計を−80〜+200%に制限。小さい効果にも変化が出るよう絶対値を四捨五入し、端数によって消える差は補正方向に1点動かす（最小0）。確率は変えない。資金移転（援助資金を含むイベント）は金銭効果を補正せず、有限の財布を維持する。
- 継続方針の補正は対象年齢・維持条件を満たして継続中のみ。単発行動の取得効果は確定の次期から育児終了まで有効、繰り返しても重複取得しない。未確定予定・取消は効果を持たない。後段ほど強い利点と負担を対にする。補正値と由来を選択前とイベント結果に示す。
- 4歳から保育所、6歳から公立小学校を無料の既定経路とする（基本生活費に含む）。私立・インターナショナルは見学、年収、成績、資金を条件とする。小学校は12歳で終了。後段に受験準備、進学、大学準備の枝を設け、年代を越えて計画できる。年齢条件・切替の排他・継続費・既定対応を事前表示する。実在の入学制度を再現するものではない。
- 実家は体力8、関係6、援助資金100万円、地域のつながりありの一つの仲間。新規ゲームには個人別状態を持たせず、援助・疲労・回復・維持条件も共通値を使う。
- メイン画面の中央にアクションマップを置き、地図上に5分類のアイコンを表示する。広い画面では地図の横幅を1000pxに固定し、狭い画面では表示枠内に縮める。メインの地図には「ACTION MAP」「今期のアクション」の見出しを置かない。右下の操作メニューは地図と独立して画面右下に固定し、地図と重なる画面幅でも分類アイコンを覆わない。アイコンを選ぶと、その分類の説明とアクションツリーだけを表示する。戻る操作でマップに戻る。未解放を含む分類内の全体を閲覧でき、半年の進行と取消は維持する。
- 広い画面では地図の絵を表示枠に合わせて広げ、5つの分類アイコンの中心を道の分岐点・終点に合わせる。画面の高さが変わっても一列へ並べ直さない。狭い画面では重なりを避けるため配置を調整する。
- ツリーには実行できる内容ごとに独立したノードを表示する。ノードを選ぶと詳細ダイアログが開き、内容・取得条件・費用・効果を確認して「このアクションを確定」または「キャンセル」を選ぶ。ダイアログ内に別の実行案の選択肢は置かない。予定済みのノードは同じダイアログから取り消せる。方針間の排他と既定経路は既存の判定を使う。
- 各実行案には任意の`visual` IDを設定でき、共通`visuals`から画像を解決する。未設定のアクションは暫定的に`hero`を表示する。個別のビジュアル制作は後でまとめて行う。
- 「現在の暮らしと取得効果」はメイン画面に置かず、家族の様子タブで現在の方針と有効な効果を表示する。
- アクションマップと分類画面の外側のメイン領域は画面内に収める。小さい画面でも分類アイコンや文字を重ねず、分類内のツリーだけを必要に応じてスクロールできる。
- マップの操作を繰り返し説明する文と、予定がないことを説明する文は表示しない。今期の予定がある場合だけ、予定内容と一括取消をマップ下に表示する。
- 画面切り替え・今期の出来事・半年進行を右下の小さな角形フローティングメニューにまとめる。大きめの半年進行アイコンを左下に置き、5つの補助アイコンをその上側から右側へ隙間なく並べる。メニューは画面の右下に固定し、地図の大きさや位置に追随させない。地図と重なる場合も分類アイコンを覆わない。操作説明の文字は表示せず、各ボタンには読み上げ用の名前を付ける。従来の下部タブ列と画面内の進行ボタンは置かない。右上には現在資金と半年の入金・支出を短い表示で並べ、タップすると収入と支出の予定内訳、および半年後の見込み資金をダイアログで表示する。内訳は予測と同じエンジン計算から公開し、合計と一致させる。右上の家族状態と現在資金の見出し、およびアクション画面上端の帯は表示しない。進行できない場合は進行操作を無効にし、理由を確認できるようにする。

受け入れ条件：

- **AC-018-A**：CLI/UIの全ノード・前提・取得状態・不足理由が一致し、未解放の操作と同一期の連続取得を拒否する。資金・年収・成績・親能力の境界を確認。
- **AC-018-B**：補正の継続／解除／履歴取得、強弱、善悪別の加算・上限・数値上下限・援助総額を検証。イベント結果に適用元を残す。
- **AC-018-C**：無操作で4歳と6歳の既定経路に入り、私立等と排他になり、卒業後の費用と効果が残らない。
- **AC-018-D**：実家の共通状態、有限援助、回復、保存再開・再送・再生一致と40期・成人後の完走を確認。旧rules-8の分岐・再生を維持。
- **AC-018-E**：PC・モバイルでマップ上の5アイコンから分類別ツリーに入り、戻るとマップへ戻る。メインの地図には「ACTION MAP」「今期のアクション」の見出しを表示せず、分類画面には見出しと戻る操作を表示する。実行案ごとのノードと接続線、未解放の詳細ダイアログ、確定・キャンセル・予定取消・進行を操作できる。詳細内に追加の実行案選択は出さない。現在の暮らしと取得効果は家族の様子だけに表示する。各実行案の画像設定と共通仮画像を確認する。短い画面と狭い画面でもメイン領域にスクロールが生じず、マップのアイコンと文字が重ならず、広い画面で地図の横幅は1000pxを超えず、幅641px以上では5アイコンの中心が地図の道の分岐点・終点に重なり、分類内のツリーを操作できる。右下の角形メニューから半年進行・4画面・出来事を操作でき、補助アイコンは進行ボタンの上側と右側に並ぶ。メニューは画面右下の固定位置にあり、地図と重なる場合も分類アイコンを覆わない。各操作の読み上げ名がある。右上の資金・入金・支出をタップすると予測内訳と半年後の資金が開き、内訳の合計が予測と一致する。面白さと調整値は人の評価が未完了。

## 年代と選択で育つ物語（2026-09-18、D-040）

実装対象：本編の既存ツリーへ、幼児の見立て遊び・タイムカプセル、科学と発明、音楽、スポーツ、家族の冒険、実家の料理と屋台、親の独立、若者の進路と巣立ちを追加する。本文・費用・分岐の正本は`config/decisions.json`、出来事は`config/events.json`。ゲーム上の誇張であり、実在の教育・起業・競技制度を再現しない。

- 入口から継続・挑戦・後年の振り返りへ、年齢と確定済みの選択をつなぐ。既存の工作体験・科学体験・進路相談・実家訪問・働き方相談も新しい枝の入口にする。
- 挑戦だけを正解にしない。同じ行動の中で、少額の身近な体験、費用と疲労を伴う大舞台、休止や方向転換を選べる。単発の大きな賞金は一度限り、継続活動には無料の終了設定を置く。未確定の予定や取消では後続・専用イベントを解放しない。
- 選択専用イベントは、履歴だけでよい思い出と、活動中だけ起きる出来事を分ける。大舞台へ挑んだ後にも必ず入賞するとは限らず、成功・珍事を独立抽選する。本文は努力と結果のつながりを示す。自動イベントへの必須回答は増やさない。
- 年代限定の珍事と一度限りの節目を増やし、既存の全年齢イベントの頻度も調整する。独立抽選・ID別の乱数・再発間隔は維持し、標準生活の複数シードで平均1〜3件/期を目安に検証する。毎期の件数保証ではない。
- 設定追加のみでrules-9 / data-9 / save-10を維持する。同一版内の内容は保存済み設定とfingerprintで識別し、既存の人生には追加内容を注入しない。

受け入れ条件：

- **AC-018-F**：異なる選択から異なる後続行動・専用イベントへ進む。幼児期の選択が後年に再登場し、前提なし・対象年齢外・取消・休止中に専用の展開が漏れない。各追加分岐の選択肢を通常の確定操作で取得できることを確認する。
- **AC-018-G**：年齢別イベント、専用イベントの一度限り・再発間隔、同一シードの再現と異なるシードの変化を確認する。3難易度の標準生活で40期と成人後に到達し、平均頻度と最頻イベントを記録する。
- **AC-018-H**：公開CLIで複数の新規経路を0〜20歳・成人後まで進め、保存再開・再送・再生で予定・取得・イベント・収支が一致する。旧設定の保存は新しいカタログで開いても変わらない。人による飽きにくさ・面白さの評価はQ-014で継続する。
