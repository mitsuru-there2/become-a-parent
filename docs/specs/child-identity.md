# S-019：子どもの隠し特性・称号・代表状態

状態：実装済み・機械検証済み（[記録](../development-plan.md)）。2026-09-22、D-083。数値はゲーム上の調整仮値であり、現実の育児効果や子どもの性格を判定するものではない。

## 隠し特性

新規ゲームの子どもに0〜100点の値を12種類持たせ、すべて0点から始める。保存と再生に含めるが、公開状態・判断詳細・イベント本文・履歴には値と増減量を渡さない。既存の公開「学び・創作」能力とは別の系列である。イベントの発生条件と確率補正には使用できる。

新コンテンツは`life_game.child_identity: true`で有効にする。設定を保存している旧ゲームは以前の状態と再生結果を保ち、途中から隠し特性を後付けしない。

| 種類 | 特性 |
| --- | --- |
| 専門スキル | 音楽センス、スポーツセンス、工作センス、ゲームセンス、探究センス、文章センス |
| 性格傾向 | 内向性、社交性、リーダーシップ、責任感、責任逃れ、粘り強さ |

各判断を**取得した時に一度だけ**、所属ルートの主特性+6、副特性+4を与える。判断名に下記の題材がある場合、対応する特性をさらに+3する。複数の語が同じ特性に当たっても、その判断からの題材補正は一回とする。DLCなどの判断は`hidden_effects`で追加補正を指定できる。0〜100点で切り詰める。ルート確定・閲覧・取得拒否は成長させず、毎期の自動成長にも含めない。

## イベントへの影響

自動イベントの`conditions`と`modifiers`は隠し特性のパスを扱う。前者は候補に入る条件、後者は既存の確率に加える百分率ポイントである。抽選・同一期最大3件・再発間隔・保存再生はS-016を維持する。隠し特性へのイベント効果は内部で適用し、変化量を公開しない。

既存イベントの補正は工作コンテストに工作25点以上+12、学習コンテストに探究25点以上+12、友だちに社交性25点以上+12、学校でのすれ違いに責任逃れ25点以上+10、音楽セッションに音楽25点以上+15、リレーにスポーツ25点以上+15、自由研究の火山に工作25点以上+12とする。元の年齢・履歴・公開パラメータ条件は維持する。

追加イベントは音楽のアンコール、リレーの飛び入り、おもちゃの修理、手作りゲーム大会、ひとりで進めた企画、班のまとめ役、係の準備の後回しの7種類。対応する音楽・スポーツ・工作・ゲーム・内向性・リーダーシップ・責任逃れが25点以上のときだけ抽選対象となる。それぞれ対象年齢以降の基本確率25〜28%、再発間隔6ターン。加えて、責任感が30点未満のときに抽選される「提出前夜の大あわて」は責任逃れを伸ばし、次の出来事への経路になる。結果は既存の公開状態または隠し特性へ作用する。8件の題材・数値は[設定](../../config/events.json)を正本とする。

## 称号と代表状態

称号は該当値が**45点以上**になった時に一度だけ獲得する。音楽・スポーツ・工作・ゲームには80点の上位称号もある。獲得済みの称号は値が下がっても残り、子どもの詳細にすべて表示する。獲得直後は画面上部に目立つお祝いを表示し、複数同時獲得もまとめて表示する。称号はイベント条件・数値効果・結末に使わない。
