## 発生と適用の共通契約

今期開始時に、表の固定ターンイベントを最大1件と、条件イベントE-09またはE-10を最大1件、ID順で提示する。条件枠はE-10を優先し、E-09は未提示なら次期へ持ち越す。提示済みイベントを取消・編集・再読で再生成しない。提示時の条件と対象分野を固定する。固定ターンのイベントはその期に必ず提示し、プレイヤーが回答するまでadvance不可。

固定イベントは各1回。E-09はt>=5で条件を満たす最初の空いた条件枠に1回。E-10は前回の提示から4ターン以上、3<=t<=38で再提示できる。tが範囲外、条件未達、または競合で選ばれなければ発生しない。選択なしのままターンを飛ばす処理はない。珍事だけは回答を求めない。

各イベントのinstance IDは `tNN:E-NN`。各選択のaction IDは `E-NN:option`。費用は確定時の家計に含め、親時間の追加消費は全選択0（会話の細かい時間を二重計上しない）。表にない効果は0、遅延はなし、予約はなし。必要金額以外の選択条件はE-09のacceptのGM>=20だけ。費用0の選択を必ず含める。表の `両親` はA/B各々、`信頼` はT_A/T_B各々。数値差分は[通常更新の後](core.md)に適用する。

表の文は初版の表示文。選択後は「『選択肢名』を選んだ」を表示し、公開の収支・親状態の増減と新しい観察を併記する。子どもの内部効果量は通常出力に出さない。

## 偶然の珍事

各ターン、通常・選択・遅延の更新後に[S-008の抽選](cli.md)で `R(seed,"child",t,"oddity")` を得る。行動から独立し、他の出来事と共存する。毎期最大1件。同じ種類は連続発生も可。

| R（0〜99） | ID・表示                                           | 効果                                                                          |
| ---------- | -------------------------------------------------- | ----------------------------------------------------------------------------- |
| 0〜9       | O-01「忘れていた返金。家計簿が一瞬だけ拍手した。」 | M+10、上限処理は通常と同じ                                                    |
| 10〜17     | O-02「家電が、今しかないという顔で止まった。」     | Mからmin(M,8)を支出、両親S+1。8に不足する分は修理を縮小したと表示し、負債なし |
| 18〜24     | O-03「家族の妙な作品が回覧板の表紙になった。」     | oddity_count+1、両親F+2・N+2                                                  |
| 25〜99     | なし                                               | なし                                                                          |

予測画面では、珍事が生じ得ることと支出上限8万円を示す。まだ起きていない乱数結果は開示しない。O-02は残金で支出を制限するため確定後に資金不足エラーを生まない。称号の回数自体を最終幸福へ加点せず、思い出とその場の充実を記録する。

## 接続の確認

- 活動と関わり → B/I/X/T/U → E-05・E-07の対象 → 本人の進路 → 成人後の暮らし・親子の連絡 → 幸福内訳。
- 仕事・分担 → S/H/F/N/G/K → E-10の兆候 → 修復・休息・支援 → 健康と関係の持越し。
- 祖父母支援 → 世話時間とGH/GR → 支援が使える期間の変化。E-09の資金・人脈は独立した支援機会。
- BP専用の発火条件はない。どのBPからも上記へ到達可能。成果への配分を減らす修復には機会費用があるが、善悪ラベルや固定バッドエンドは付けない。

## 受け入れ条件

AC-005：固定8件が該当期に一度ずつ提示される。E-10が優先されてもE-09を失わない。E-10は最低4期の間隔を守る。全選択IDに効果・費用・表示文があり、未回答は確定不可。選択の編集だけでは効果なし。

AC-005-L：t=25のlisten→t=27で条件成立なら予約した分野に+2、不成立なら0、どちらも予約削除。t=38のrepair→40で消化し、finished時に予約0。E-10不発生・repair未選択でも全期間が進む。

AC-005-R：R=0/9/10/17/18/24/25/99の境界で表と一致。M=3のO-02は支出3、残金0。O-03の称号回数だけ変更しても最終幸福は変わらない（F/Nまで変更する別ケースは区別）。
