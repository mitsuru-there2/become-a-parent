# 初回ビジュアル案

正式HERO `assets/marketing/hero.png` をスタイル参照にして生成した、ゲーム内ビジュアルの試作3点。

## イベント

- ファイル：`event-washing-machine-v1.png`
- 題材：洗濯機の泡がリビングへあふれる、困るが怖くない日常イベント
- 用途想定：イベントダイアログ
- 指示：白黒1bitのピクセルイラスト。両親と子ども、洗濯機、泡、洗濯物を描く。文字・UI・ロゴなし。

## 判断

- ファイル：`decision-branch-v1.png`
- 題材：家で過ごすか外出するか、二つの扉の前で迷う家族
- 用途想定：判断・選択ダイアログ
- 指示：中央に家族、左右に本とランプのある室内／リュックとボールのある外出先。どちらが正解とも示さない。文字・UI・ロゴなし。

## 子どもの状態

- ファイル：`child-state-curious-v1.png`
- 題材：子どもが自分からブロックや工作に没頭している状態
- 用途想定：子どもの状態詳細
- 指示：子どもを主役に、見守る両親と創作物を配置。主体性・好奇心・安心感を表情と姿勢で示す。文字・UI・ロゴなし。

## 共通仕様

- 生成方式：組み込み画像生成
- 参照画像：`assets/marketing/hero.png`
- 出力：PNG、イベント／判断は768 × 576 px、子どもの状態参考画像は512 × 384 px、RGB
- 軽量化：表示用途に合わせて縮小し、`sips --optimizeColorForSharing` でPNGを最適化。容量は約300〜560KB。
- 画風：黒背景、白主体、粗いドット、段差のある輪郭、規則的なディザ、簡素な四角い人物
